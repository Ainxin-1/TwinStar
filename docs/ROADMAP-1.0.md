## 阶段 2 冻结清单（当前定稿事实）

冻结对象 = 以下协议面，冻结后在 1.0 内不再变更；任何变更必须 bump ALPN 次版本号并更新 README 兼容性说明。

| 协议面 | 定稿值 | 位置 |
|---|---|---|
| ALPN | `twinstar/1` | `net.rs` `ALPN` |
| 元数据 FileMeta | `name/size/fingerprint/sha256/chunks/sender`（chunks、sender 为 `serde(default)` 可选字段） | `transfer.rs` |
| 能力协商位 | `1<<63` 并行接收；`1<<62` 接收方拒绝 | `transfer.rs` |
| 分块魔数 | `TSC1` | `transfer.rs` |
| 并行参数 | 门槛 16 MiB，4 路并发 | `transfer.rs` |
| 局域网发现 | UDP 广播 `:39617`，魔数 `TWINSTAR-DISC-v1`，3s 间隔 / 12s 超时 | `disc.rs` |
| 连接码 | Ed25519 公钥 SHA-256 摘要（64 hex），支持 `id@ip:port,...` 带地址写法 | `net.rs` |

互通矩阵（冻结验收测试要求）：

| 发送端 \ 接收端 | v0.10.1 | v0.11+ |
|---|---|---|
| v0.10.1 | ✔（既有） | ✔ FileMeta 无 sender → 缺省空串，弹窗回退连接码短哈希 |
| v0.11+ | ✔ 新接收端可拒：REJECTED 位，v0.10.1 发送端得明确失败不误报成功 | ✔ 全能力 |

## 工作纪律（沿用）

- 同文件多处修改禁止并行 Edit。
- 沙箱杀前台长跑 cargo → 后台跑；cargo 用 `-j 2` 缓解杀软写竞态。
- 沙箱封 `git rm`；目录改名用"新建 + 逐个 mv 子项 + git add -A"。
- push 报错先查远端（可能已受理）；二进制不进 git，发版走 `gh release create` + `gh release upload`。
